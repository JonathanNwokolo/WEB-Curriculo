# WEB-Curriculo

Este projeto é um currículo web simples.

## Estrutura do Projeto
- `index.html`: Página principal do currículo.
- `img/`: Pasta para imagens utilizadas no currículo.

## Como usar
Abra o arquivo `index.html` em seu navegador para visualizar o currículo.

## Personalização
Edite o arquivo `index.html` para alterar as informações do currículo conforme necessário.
